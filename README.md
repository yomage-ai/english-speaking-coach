# 英语口语教练

在旅行、点餐、面试等情景中练习英语，聊完后查看表达建议、复习卡片和学习进度。你只需说想练什么，Codex 负责准备和保存记录。

练习对话全程使用英语；听到中文或中英混合表达时，教练会用英语帮你确认意思。教练用开放问题引导，不给备选答案；需要时仍会教你一句可用的说法。网页保留中文翻译和书面复盘。

## 怎么开始

安装完成后，打开 Voice，再发送下面这句，然后就可以开始对话学习英语啦：

> /$english-speaking-coach 帮我练英语。

也可以从输入框的 Skill 选择菜单中选中 **English Speaking Coach**。新安装的插件在新任务中使用。普通文字任务会进行文字练习；实时双语伴读要在活动 Voice 中使用。

需要排查问题时直接说，例如“检查双语页面为什么没有翻译”。Codex 会暂停练习，用你当前的语言处理，等你要求继续时再恢复练习。

每次用简短开场介绍场景、双方角色和你的目标，然后开始对话。AI 会按你选择的纠错方式帮助你组织表达，并引导情景的下一步，给你说需求、讲理由和提问的机会。新一轮会参考学习记录选择新场景。

## 会看到哪些页面

每次开始练习，Codex 都会自动打开本地学习页面；结束后展示本次复盘。页面包含：

| 页面 | 你可以做什么 |
| --- | --- |
| 双语伴随页 | 边聊边看原话、中文翻译和当前一句表达提示 |
| 课后复盘 | 区分本次实际练习与后续建议；切换页面仍能找回整理结果 |
| 学习首页 / 学习回顾 | 首页开始下一步，回顾查看一段时间的练习变化 |
| 本地学习数据 | 打开目录、下载完整备份、恢复备份或使用另一份已复制档案 |
| 复习卡片 | 先自己想，再翻面查看答案；听完整英文的本地系统朗读，或展开读法与记忆提示 |

正式插件包已包含适合各支持平台的本地程序；Codex 自动校验、选择并启动，首次练习无需再下载后台。**不需要安装 Python、Node.js 或 Go，也不用手动启动程序。** 旧版单独 Skill 安装仍由 Codex 自动获取对应程序。支持的桌面环境及边界见下文。

系统朗读只读可以直接说出口的完整闪卡英文与复盘建议，不读带省略号等占位符的句型模板，也不读你的原话。点击“朗读英文”播放，再点停止；“慢速”会用清晰慢速逐句播放。程序优先选择可靠的本地英语声音、分段朗读，并避免切速时的新旧播放互相中断。它不需要 API Key、付费语音服务或麦克风权限。音色、读音与音量仍由系统及浏览器决定；没有合适本地英语声音时页面会明确提示。

朗读与 Voice 独立，不是当时练习的原声回放；翻卡、听音和跟读不自动保存为练习表现，也不改变掌握状态。目前不增加 Web 录音、语音识别或新的练习日志。

## 使用前了解

- 在 macOS、Windows 或 Linux 上能安装 Skill、访问本地文件的 Codex 中使用。实时双语还需要宿主在会中提供双方转写；普通网页聊天和手机端不自动具备此能力。
- 双语伴随和独立课后复盘使用现有 ChatGPT 登录及账户额度，无需另外填写 API Key；字幕显示取决于语音转写的可用情况。
- 用户只在真正需要时处理 Codex 登录、Voice 麦克风权限或系统要求的运行／文件访问批准。插件不会绕过系统限制；Codex 会说明具体原因，不要求安装开发环境。
- 学习档案与 Skill 程序分开，新用户默认保存在 Skill 外。网页的“打开学习目录”可查看本机数据。AI 对话和翻译仍使用所连接的模型服务；双语伴随页会临时保留近期转写与译文。默认目录是 `~/.codex/english-speaking-coach/data`，首次使用自动创建，不要求安装时选位置。换电脑时，在新电脑恢复备份或使用已复制的学习目录，也可以让 Codex 代办；原目录保留。

复盘由本地服务独立生成，离开当前聊天后仍会继续；页面先展示已校验来源的表达建议，再补全并保存完整复盘。模型只负责有语义判断的内容，逐回合覆盖与词义记账由程序补齐并校验，避免长对话因为重复输出机械字段而超时。失败时来源和待办保留，可重试；模型生成仍不保证固定秒数。

翻译连接失败时，原文继续更新；网页会说明原因并提供重试。后台可用不等于宿主一定提供实时转写，Codex 会分别检查。

原生 Voice 可能自行回应或改述 Agent 的英文，因此 Skill 不能保证它每次都保持英文或正确判断停顿；字幕也不能控制语音。这是当前宿主的能力边界。
