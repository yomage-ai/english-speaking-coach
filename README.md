# 英语口语教练

在旅行、点餐、面试等情景中练习英语，聊完后查看表达建议、复习卡片和学习进度。你只需说想练什么，Codex 负责准备和保存记录。

## 怎么开始

安装完成后，打开 Voice，再发送下面这句，然后就可以开始对话学习英语啦：

> /$english-speaking-coach 帮我练英语。

也可以从输入框的 Skill 选择菜单中选中 **English Speaking Coach** 。

每次会介绍场景、双方角色和你的目标，然后开始对话。AI 会根据你的表达接着聊，给你说需求、讲理由和提问的机会。新一轮会参考学习记录选择新场景。

## 会看到哪些页面

每次开始练习，Codex 都会自动打开本地学习页面；结束后展示本次复盘。页面包含：

| 页面 | 你可以做什么 |
| --- | --- |
| 双语伴随页 | 边聊边看英文原话，需要时查看中文翻译 |
| 课后复盘 | 看本次精选表达、改进建议和练习重点 |
| 学习档案 | 查看过去的课次、常用词句和学习进度 |
| 复习卡片 | 先自己想，再翻面查看答案 |

## 使用前了解

- 在能安装 Skill、访问本地文件的 Codex 中使用。
- 双语伴随使用现有 ChatGPT 登录及账户额度，无需另外填写 API Key；字幕显示取决于语音转写的可用情况。
- 学习档案保存在本机。AI 对话和翻译仍使用所连接的模型服务；双语伴随页会临时保留近期转写与译文。换电脑时可以让 Codex 帮你迁移档案。
