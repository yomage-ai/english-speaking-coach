# English Speaking Coach · 英语口语教练

通过自然英语对话练习真实表达，并用本地学习档案、翻面闪卡和成长记录支持持续练习。重点是把想法说清楚：提问、解释、澄清、描述和回应。词汇与语法服务于沟通。

## 怎么使用

- “我想去外企面试，帮我练自我介绍。”
- “我准备出国旅行，练一下向酒店前台询问信息。”
- “我今天只有两分钟，打开生词本，先显示英文让我猜意思。”
- “继续上次的对话，需要时用中文帮我一下。”
- “打开双语伴随页，我们用英文聊，中文翻译放在网页上。”

用户只需说出练习目标、话题或想回顾的内容。Agent 负责安装检查、初始化、恢复进度、保存、验证和打开页面。不会要求每次练习前填写问卷或先访问网页。

## 学习档案

| 页面 | 用途 |
| --- | --- |
| 双语伴随（可选） | Voice 双方英文原话与中文翻译，支持按需看中文及回看 |
| 学习概览 | 最近课次、主题生词本和短时回顾入口 |
| 对话记录 | 精选原话、表达建议、当次总结和下次方向 |
| 生词与表达 | 一条词句一张可翻转卡片；中文想英文、英文想中文或中英对照 |
| 统计回顾 | 所选期间的练习概况、最多三个词句摘要和少量回顾建议 |
| 词句进展 | 可搜索和筛选的列表，每页 20 条；详情历史每页 10 条，可筛选月份 |

统计只使用所选期间及此前的记录，不混入后来的成功。首次记录与可比较的进步分开；理解词义、顺畅朗读和自主运用分别观察。查看卡片不会记成掌握。跨日、换场景的成功支持“表达已较稳定”，这是产品口径，不是考试评分或永久掌握证明。

## 数据属于用户

网页程序随 skill 安装，真实学习数据在练习后生成。

- 新用户默认使用 `<skill>/data`；已有本机路径配置优先，不重新创建第二份档案。
- 可以说：“把我的档案迁到这个知识库或 Obsidian 子目录：……，保留原数据。”Agent 复制、校验后切换。
- 原始记录采用 Markdown；索引和网页视图可以重建。Obsidian 是可选阅读工具。
- 默认 data 写入后在 skill 外保存一份最新恢复副本。更新或卸载前 Agent 仍需保留数据；这不是云同步或完整版本备份。
- 新窗口能恢复的前提是能够读取同一台机器上的配置与学习数据。换电脑需迁移数据并重新配置路径。

用户的档案、配置、备份、录音和私人截图均不属于这个仓库。仓库测试只使用明确虚构的样本。

## 环境与实际边界

运行工具需要 Python 3.10+，只使用标准库，无外部数据库或 Node 运行依赖。可选双语伴随需要 Python 3.11+、支持 app-server 的 Codex 和现有 ChatGPT 登录；使用账户额度，无须新增 API Key。Agent 负责检查运行环境。

已在 macOS 验证全新初始化、保存、跨进程恢复、打开本地网页，以及没有额外服务管理 skill 时的内置 launchd 启动。存在宿主管理器时优先复用；内置管理只维持当前登录会话，不自动添加登录启动。Linux/Windows 的存储与视图逻辑由跨平台 CI 检查；持续服务由 Agent 使用宿主的原生管理器完成，原生桌面和 Voice 流程尚未实机验证。

Skill 指令和使用说明支持简体中文与英文，按用户当前语言交流；网页导航目前以中文为主，保留英文学习内容。

Voice 沉淀依赖宿主实际提供转写、结束信号和工具执行机会。默认仅保存学习所需片段，不后台录音。只有真实可访问的音频才能支持朗读判断；没有音频时只记录能够观察到的理解或表达表现。不会保证任意 Voice 宿主都有自动结束回调。

## 双语伴随的实际边界

用户用原有 Codex Voice 说英语，固定本地页面先显示英文，随后补充中文。Agent 只绑定当前练习任务与 Voice，不要求逐句转发；空闲时没有模型轮次。默认使用 GPT-5.6 Luna 的 low 模式，以实际登录提供的模型为准，不会静默切换或购买服务。

临时双方转写与译文保存在学习目录的 `Live/` 内，与正式精选课次和掌握证据分开。每页至多 40 条，可回看近期场次；开始新伴随时清理超过 7 天的缓存。说“不用双语伴随了”即可由 Agent 关闭后续自动启用。

每场 Voice 都需要 Agent 重新绑定；同一任务里连续开新 Voice 也一样。若宿主没有给 Agent 执行机会，可能漏掉会中字幕。你可以说“恢复刚才结束的双语对话”，由 Agent 核对并补译，页面会明确标注“结束后恢复”。这不会打断另一场正在进行的字幕，也不会把补译当作实时覆盖。中文教学说明里引用的英文例句会单独补充中文句意。

已验证程序增量读取和真实 Codex 翻译请求。**Voice 会中多久写出文字、端到端延迟和漏句情况仍需实际 Voice 试用**，不能从结束后的日志推断。Skill 无法保证宿主永远自动加载指令或发出结束回调。Agent 会显示实际就绪、等待、结束和错误状态。实现与恢复说明见 [双语伴随](references/live-companion.md)。
