# 英语口语教练

在旅行、点餐、面试等各种情景中练习英语，聊完后查看表达建议、复习卡片和学习进度。你只需说想练什么，Codex 会准备练习并保存记录。

## 怎么开始

安装完成后，在新任务中开始使用：

打开 Voice，然后发送 `/$english-speaking-coach`，也可以从输入框的 Skill 菜单中选择 **English Speaking Coach**。

tip：练习对话使用英语。如果一时不知道怎么说，可以直接用中文表达意思；教练会用英语确认你的意思，再帮助你组织可用的说法。

## 练习后可以查看

| 页面 | 内容 |
| --- | --- |
| 双语伴随页 | 练习时查看双方原话和中文翻译 |
| 课后复盘 | 查看本次表达、改进建议和下一步重点 |
| 学习回顾 | 查看过去的练习和一段时间内的变化 |
| 复习卡片 | 复习常用词句、分组、重音和语调提示 |
| 本地学习数据 | 打开学习目录，备份、恢复或迁移学习档案 |

## 使用前了解

- 语音练习需要 Voice。
- 使用现有的 ChatGPT 登录和账户额度，不需要另填 API Key。只有出现提示时，才需要你处理登录、麦克风或系统文件权限。
- 学习档案保存在本机。AI 对话和翻译会使用你选择的模型服务。
